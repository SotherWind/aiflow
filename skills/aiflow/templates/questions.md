# 问题台账

> 问题问清、共识确认后按真实对话整理；中途保存仅在用户明确要求时进行。
> 归档规则见 `references/clarification-records.md`。跨阶段追加，保留原话与历史决定。
> 状态：待问 / 待答复 / 已解决 / 按推荐 / 移出本轮 / 作废。阶段收尾不得有未决项。
> 「已解决 / 按推荐 / 移出本轮」填写真实用户答复；「作废」在备注写原因。
> `pending_decisions` 与已落档的「待问 / 待答复」编号一致。
> 备注按需保留展示过的选项、推荐前提、组合限制和调研来源；多选保留完整答复。
